# 真机回归矩阵

每次只使用 debug：改动 → 单测/打包/lint → 核验证书 → 覆盖安装 → 重启受影响作用域 → 日志及界面验证。修改 `system_server` Hook 后必须重启手机。保留原设置，测试后恢复；不把宿主 APK、私人通知、密钥或设备数据提交。

| 功能 | 必测场景 | 通过标准 |
| --- | --- | --- |
| 卡片列表 | 冷加载、热分发、反复开关、已有 ≥15 项 | 原列表不多算模块卡片；显示恰好一张模块入口；原项目顺序不变 |
| 应用卡上限 | 开关关/开、重复 resId、超限列表保存 | 关时官方 -2；开时正常查重；保存没有丢尾项或写入模块卡片 |
| 快捷面板 | 入口点击、底部关闭、切后台、熄亮屏、Activity 重建 | 不误触打开；关闭回官方列表；无残留遮罩、动画锁或手势排除区 |
| 长按壁纸 | 禁用开关开/关，各长按一秒 | 开时阻止编辑，关时进入原厂编辑；关闭面板后仍成立 |
| 双击唤醒 | 被选应用、未选应用、主屏/背屏、KEY/POWER/通知 | 只过滤选中前台应用的背屏双击，不受历史后台任务影响 |
| 背屏保护 | 开关开/关、正屏亮/灭 | 仅按设置移除官方指定保护提示，其他防误触行为保留 |
| 取件码 | 单码/多码、多驿站、重复码、非法文本 | 多码才增强；无关通知与单码保持官方逻辑 |
| 通知入口 | notify(id,n)、notify(tag,id,n) | 每次只加工/捕获一次，原始调用者 Notification 不变 |
| 刷新 | 勾选/全选/全不选、连续多次、批次间隔 >2s | 各 RemoteViews/JSON 同步；页面会话不漂移；Parcel 大小不累计增长 |
| 通知生命周期 | 取消、原 ID 更新、确认取件、关闭增强 | 不复活已取消通知，不覆盖更新内容；确认关闭对应页面；关闭后不再增强刷新 |
| 主题与资源 | 主题页反复进入、切换壁纸、资产修复 | 数据同步不阻塞主线程、不并发覆盖；修复有界且不保留 Activity |
| 进程/资源 | 多次启动、重建、空闲、缓存被清理 | Hook 不重复，后台队列有界，空闲线程退出，图片缓存可重建 |

本轮执行结果见 [2026-09-27 验证记录](validation-2026-09-27.md)。矩阵列出需要覆盖的范围，不代表每个项目都已通过。
